# Diplom_3

## Обзор проекта
Diplom_3 — это третяя часть дипломного проекта по автоматизации тестирования веб-приложений.

### Директория pages
В директории `pages` содержится следующие файлы:
- `profile_page.py`: Методы для страницы профиля.
- `login_page.py`: Методы для страницы входа.
- `main_page.py`: Методы для главной страницы.
- `order_feed_page.py`: Методы для страницы обновлений заказов.
- `base_page.py`: Методы для всех страниц.

### Директория locators
В директории `locators` содержатся файлы с локаторами для веб-элементов. Эти локаторы используются для идентификации UI-элементов на веб-страницах.
- `profile_page_locators.py`: Локаторы для страницы профиля.
- `login_page_locators.py`: Локаторы для страницы входа.
- `base_page_locators.py`: Общие локаторы.
- `password_page_locators.py`: Локаторы для страницы пароля.
- `main_page_locators.py`: Локаторы для главной страницы.

### Директория tests
В директории `tests` содержатся тестовые файлы для различных страниц. Тесты написаны с использованием pytest.
- `test_main_page.py`: Тесты главной страницы.
- `test_profile_page.py`: Тесты страницы профиля.
- `test_password_page.py`: Тесты страницы пароля.
- `test_order_page.py`: Тесты страницы заказа.

### Дополнительные файлы
- `conftest.py`: Конфигурационный файл для pytest, содержащий настройки или фикстуры.
- `data.py`: Общие переменные.

## Запуск тестов
Чтобы запустить все тесты, используйте pytest.
